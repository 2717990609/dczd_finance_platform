# 组织与人员开发说明

原财务 A2 的「组织与人员」分内部组织、外部合作、全部人员、销售类别、职位配置和总监归属。人员详情含组织任职、业务职责、来源身份和变更记录。公司类型、销售类别、公司成员关系、职位和业务职责在代码及数据库中各有独立字段和生效规则。

| 原系统数据 | 本系统处理 |
| --- | --- |
| 销售公司档案有内部、外部或待确认类型。组织目录可关联内部销售公司 | 组织主键沿用原公司成员范围对应的组织 ID，销售公司记录带明确类型。当前父级通过组织树读取 |
| 销售类别有独立名称、启停及公司分类历史 | 类别主键与公司有效区间分开保存。授权人员可维护类别，并为一家公司或同一页选择的多家公司调整类别 |
| 公司成员有负责人、管理人员、成员角色，可关联主要任职和兼任 | 沿用任职记录的人员、组织、角色和时间。导入可保留成员对应的主要任职或兼任 |
| 业务职责按组织、项目或产品配置，组长和团队负责人可同时任职 | 既有「计提任职」维护已接入的大春 AI 角色，继续按职责、范围和支付时点匹配。「业务职责」维护实战班代理推荐、资源推荐和团队总监。可登记人员或组织，并在同一范围结束或交接任职 |

组织页面使用当前组织层级。人员任职与类别历史使用各条记录的有效区间。历史结果按已保存的组织、订单及规则引用查询。销售类别按产品规则和对应业务时点参与计提。

组织数据先导入独立本机数据库，逐项核对类型、启停状态、分类历史及任职。公司目录使用分页查询，按需读取单家公司的类别历史，组织任职复用现有查询入口。


## 实战班业务职责

原财务将健康观念实战班和家庭教育实战班登记为两个产品，分别属于对应项目。组织导入保留职责记录指向的产品或项目 ID。原团队总监分项读取订单确认的最近一级总监。原任职档案将该职责登记在家庭教育实战班的组织主体，不能由档案推导健康观念实战班的收款人。

工作台可按主体、职责、范围和日期查询。从销售公司或人员任职历史也可下钻。交接按同一北京时间结束原任职并建立新任职，沿用原职责、适用范围及计划结束时间。再次导入组织快照时保留本平台已维护的任职。

业务职责供组织查询和维护。计提仍由各产品的已生效规则决定。现有大春 AI「计提任职」继续使用已有资格口径。


## 销售类别调整

调整公司类别时使用数据库保存时点。原类别在同一时点结束，新类别从该时点生效。每家公司同时核对当前类别和生效起点，遇到旧页面提交冲突时重新读取。批量操作在一个事务内完成。仍有启用公司使用的类别须先完成调整再停用，历史类别继续可查。

大春 AI 按付款时点匹配销售类别。系统通过已解析的公司主键，读取本平台生效的类别变更。变更前仍使用原有计提类别资料。规则编辑可选择启用的类别，已发布规则保留类别主键。调整完成后标记对应的开放账期待试算，正式结算保留原记录。实战班按各期规则配置的公司范围区分个人和公司计提。

组织快照继续补充类别历史。本平台维护的类别和变更起点保留，来源历史补充到本平台接续时点为止。
